# matter

A simple tool for creating things that matter.

## Setup

Add a `.env.development` file with a `VITE_CERT_PATH` variable set to an HTTPS certificate (can be generated by following [these instructions](https://graceydev.hashnode.dev/enabling-https-for-live-server-visual-studio-code-extension)) for [vite-plugin-basic-ssl](https://github.com/vitejs/vite-plugin-basic-ssl).

Note: Running on SSL improves DX (by generating UUIDs via `crypto`) and will allow for better UX as well (with access to other features) down the road.

## Usage

```bash
$ npm install # or pnpm install or yarn install
```

## Available Scripts

In the project directory, you can run:

### `npm run dev` or `npm start`

Runs the app in the development mode.<br>
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

The page will reload if you make edits.<br>

### `npm run build`

Builds the app for production to the `dist` folder.<br>
It correctly bundles Solid in production mode and optimizes the build for the best performance.

The build is minified and the filenames include the hashes.<br>
Your app is ready to be deployed!

## Deployment

You can deploy the `dist` folder to any static host provider (netlify, surge, now, etc.)
